# 贷款进件材料齐套业务资料库

> 建档日期：2026-08-16  
> 用途：为项目的材料齐套业务边界、架构演进叙事、测试场景和 RAG 语料设计提供可追溯依据。  
> 边界：这些公开资料只用于说明“申请材料会如何变化、影像如何提交、缺件如何补正”。本项目不据此实现贷款准入、额度、估值、风险或审批结论。

## 目录

- [业务问题分类](./01-business-problem-taxonomy.md)：从公开事实抽象出的材料齐套问题，而不是授信问题。
- [架构演进证据映射](./02-architecture-evolution-evidence.md)：为什么从确定性 Workflow 演进到 Audit Agent，再到 Exception Recovery Sub-Agent。
- [来源索引](./03-source-index.md)：来源机构、页面、事实摘要、适用类别和采集日期。

## 使用规则

1. 产品演示中的业务陈述必须能回到来源索引，或明确标记为脱敏演示设定。
2. 公开来源不是银行内部 Requirement 的替代品；真实模式仍以版本化的内部材料清单为准。
3. 公开页面里涉及贷款资格、风险、额度、利率和审批的内容不进入本项目的 Requirement Corpus。
4. 抓取页面后必须保存 Raw Snapshot、来源 URL、抓取时间、内容 Hash 和解析版本，不能只保留手工摘要。
5. 地区或机构差异必须进入 Metadata；不能把北京、南京、广州的要求合并成一条“全国统一规则”。
