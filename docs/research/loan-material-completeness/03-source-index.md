# 来源索引

> 采集日期：2026-08-16。以下均为银行或政府公开页面。摘要为项目用途的事实归纳，不是原文摘录，也不代表本项目可以据此作贷款审批判断。

## 1. 产品、分行与角色差异

### 中国工商银行：个人房产抵押消费与经营组合贷款

- 机构：中国工商银行
- URL：https://www.icbc.com.cn/page/721852475778039857.html
- 页面事实：申请资料涉及借款人及配偶的身份证、户籍和婚姻状况材料；经营用途还需经营证明；另需房产权属和贷款行要求的资料。页面提示具体办理标准以当地分行规定为准。
- 对项目的支持：`product / loan_purpose / person_role / branch` 必须参与动态清单和 Metadata 过滤。

### 北京住房公积金管理中心：住房公积金个人住房贷款申请操作详解

- 机构：北京住房公积金管理中心
- URL：https://gjj.beijing.gov.cn/web/zwfw5/386727/386737/386740/11046897/index.html
- 页面日期：2026-06-08
- 页面事实：个人身份、购房、卖方和特殊情况材料分组；已婚者需夫妻双方，共有人逐人提供；结婚、离婚、未婚的材料要求不同；新建房、二手房、离退休和异地缴存存在条件材料；组合贷款商贷部分按银行要求准备。
- 对项目的支持：清单必须按人员角色、婚姻状态、房屋/产品场景和特殊事实动态生成。

### 安康市人民政府：不动产抵押登记材料清单

- 机构：安康市自然资源局
- URL：https://www.ankang.gov.cn/Content-2619011.html
- 页面日期：2023-08-30
- 页面事实：自然人、企业、抵押权人、受托人对应不同身份证明和授权材料；不符合登记要求时书面告知需补充资料。
- 对项目的支持：Owner/Role 不是简单的“借款人/配偶”二分类；补件任务必须绑定具体人员与材料。

## 2. 页级影像完整性与清晰度

### 广州住房公积金管理中心：个人住房公积金贷款服务指南

- 机构：广州市住房公积金管理中心
- URL：https://www.yuexiu.gov.cn/ggfw/ztfw/zf/gjj/content/post_9677863.html
- 页面日期：2024-05-30
- 页面事实：身份证要求正反面；婚姻资料要求包含盖章页和登记信息页；不动产权证要求权利人、共有情况、房屋信息、附记和图纸页；合同按类型要求关键页或全部页面；上传内容须完整、无遮挡、清晰可见。
- 对项目的支持：齐套校验必须到 Page/Required Page 层，不能只检查材料文件名；不可读、缺页和多页归组是核心场景。

## 3. 电子证照与数据共享

### 北京住房公积金管理中心：优化贷款服务十条措施

- 机构：北京住房公积金管理中心
- URL：https://gjj.beijing.gov.cn/web/zwgk61/2024zcwj/436433464/436433467/436438969/index.html
- 文件状态：现行有效
- 页面事实：能调用身份证、婚姻关系、户口等电子证照核实时，可免提交相应原件；部分原由借款人提供的材料改由业务机构联系取得。
- 对项目的支持：Requirement 要表达“必须有有效证据”而不是“必须上传纸张”；`source_mode` 和电子核验结果会改变材料状态。

### 广州住房公积金管理中心：异地公积金信息

- 机构：广州市住房公积金管理中心
- URL：https://www.yuexiu.gov.cn/ggfw/ztfw/zf/gjj/content/post_9677863.html
- 页面事实：部分异地缴存信息可通过数据共享或电子码取得；无法判断连续缴存时仍需补充明细。
- 对项目的支持：数据共享成功、失败和替代材料属于同一 Requirement 的不同证据路径。

## 4. 补件与长流程恢复

### 浙江省住房和城乡建设厅：住房公积金个人住房贷款业务规范

- 机构：浙江省住房和城乡建设厅
- URL：https://zjjcmspublic.oss-cn-hangzhou-zwynet-d01-a.internet.cloud.zj.gov.cn/jcms_files/jcms1/web3162/site/attach/0/5a498dec3a7d4ffb91425088d5ae8d5f.pdf
- 页面事实：贷款申请材料不齐全或不符合要求时，受理人员应一次性告知需补正材料；对资料有异议时，补充资料后再答复。
- 对项目的支持：补件清单应一次汇总、绑定依据并持久化，而不是一次只弹出一个随机问题。

### 江门市人民政府：缺少部分公积金贷款申请材料如何处理

- 机构：江门市人民政府，来源标注广东省住房和城乡建设厅
- URL：https://www.jiangmen.gov.cn/gzhd/zhzw/content/post_3318575.html
- 页面日期：2025-06-20
- 页面事实：资料不齐全时可先行受理，待补齐后再提交审批。
- 对项目的支持：`WAITING_SUPPLEMENT` 是可恢复业务状态；补件后应从持久化 Thread 恢复并重新计算受影响任务。

### 国家金融监督管理总局厦门监管局：个人住房贷款办理规范相关通知

- 机构：国家金融监督管理总局厦门监管局
- URL：https://www.nfra.gov.cn/branch/xiamen/view/pages/common/ItemDetail.html?docId=1255978&itemId=4210
- 页面事实：银行应明确收齐材料等办理时点；收齐材料后开具交接单；审查审批阶段要求补充资料时应一次性告知。
- 对项目的支持：进件材料状态、交接时间、补件通知和后续恢复需要可审计事件，而不是只保留前端临时状态。
